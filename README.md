# flowlet

`flowlet` 是一个轻量的工作流、配置、分发与并行执行基础库。

它提供：

- `ExecutableUnit` / `Kernel` / `Workflow`
- `Dispatcher`
- `BaseConfig` / `BaseConfigContainer` / `BaseBranchConfig`
- `ThreadParallelWorkflow` / `RayParallelWorkflow`
- `Default` / `Placeholder` / `Emptyholder` / `Voidholder`

更详细的说明见 [docs/flowlet.md](docs/flowlet.md)。
